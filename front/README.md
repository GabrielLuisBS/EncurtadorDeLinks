# Linkly — front

React + Vite + TypeScript. Documentação completa do projeto (setup, arquitetura, deploy) está no [README da raiz](../README.md).

## Scripts

```bash
npm run dev -w front      # dev server (HMR)
npm run build -w front    # build de produção
npm run lint -w front     # oxlint
```

Requer `VITE_API_URL` apontando para a API do back — ver `.env.example`.
